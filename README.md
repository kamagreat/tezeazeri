# Тренажер азербайджанского языка - Недвижимость

## 🎯 Новые возможности

### Примеры использования слов в предложениях
В разделе **Тестирование** после каждого ответа (правильного или неправильного) теперь отображаются примеры использования слов в предложениях:

- **Азербайджанский текст** (курсив, синий цвет)
- **Русский перевод** (серый цвет)

### Примеры для каждого слова:

1. **Layihə** (Проект)
   - AZ: "Layihə 2025-ci ildə tamamlanacaq."
   - RU: "Проект будет завершен в 2025 году."

2. **Mənzil** (Квартира)
   - AZ: "Mənzil dənizə yaxın yerləşir."
   - RU: "Квартира расположена близко к морю."

3. **İcarə** (Аренда)
   - AZ: "İcarə müqaviləsi 1 il müddətinə bağlanır."
   - RU: "Договор аренды заключается на 1 год."

4. **Investisiya** (Инвестиция)
   - AZ: "Investisiya gələcək üçün sərfəli imkan yaradır."
   - RU: "Инвестиция создает выгодную возможность для будущего."

5. **Daşınmaz əmlak** (Недвижимость)
   - AZ: "Bu daşınmaz əmlak yüksək gəlir gətirir."
   - RU: "Эта недвижимость приносит высокий доход."

6. **Yaşayış kompleksi** (Жилой комплекс)
   - AZ: "Yaşayış kompleksində hovuz və fitness mərkəzi var."
   - RU: "В жилом комплексе есть бассейн и фитнес-центр."

## 🚀 Как использовать

1. Откройте файл `deepseek_html_20250823_8bb39b.html` в браузере
2. Перейдите в раздел **Тестирование**
3. Отвечайте на вопросы
4. После каждого ответа увидите пример использования слова в предложении

## ✨ Особенности

- Примеры появляются автоматически после ответа
- Красивое оформление с иконкой лампочки
- Автоматическое скрытие при переходе к следующему вопросу
- Работает как для правильных, так и для неправильных ответов
