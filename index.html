🎯 Тренажер азербайджанского языка

✨ Новые возможности

В разделе Тестирование после каждого ответа теперь отображаются примеры использования слов в предложениях!

📝 Примеры использования

Layihə (Проект)
AZ: "Layihə 2025-ci ildə tamamlanacaq."
RU: "Проект будет завершен в 2025 году."
Mənzil (Квартира)
AZ: "Mənzil dənizə yaxın yerləşir."
RU: "Квартира расположена близко к морю."

🚀 Как использовать

  1. Скачайте файл тренажера
  2. Откройте его в браузере
  3. Перейдите в раздел "Тестирование"
  4. Отвечайте на вопросы и изучайте примеры!
📖 Открыть тренажер

💡 Особенности

  • Примеры появляются автоматически после ответа
  • Красивое оформление с иконкой лампочки
  • Автоматическое скрытие при переходе к следующему вопросу
  • Работает как для правильных, так и для неправильных ответов
